Leeyes Unicode Hack
===================

Leeyes 2.6.1 を、Unicode文字や長いファイル名を含むフォルダ・画像・書庫で
利用しやすくするためのフックDLLとインジェクタです。

Leeyes本体は主にANSI/CP932のパスを前提としているため、Unicode文字を含む
パスが「?」に置き換わり、画像や書庫を開けない場合があります。本プロジェクトは
LeeyesおよびSusieプラグインのファイルアクセスを補完し、実際のUnicodeパスへ
フォールバックさせます。


動作環境
--------

- Windows 10/11（Win32版）で動作確認
- Leeyes 2.6.1
- 対応するSusieプラグイン
- Visual Studio 2022でビルド可能

Leeyes本体、Susieプラグイン、7z.dllなどの第三者バイナリは本リポジトリには
含めていません。各ソフトウェアの配布元から入手してください。


インストールと使用方法
------------------------

1. Leeyes本体のフォルダに、以下のファイルを配置します。

   - LeeyesW.exe
   - inject_dll.dll
   - inject_dll.ini

2. `inject_dll.ini.sample` を `inject_dll.ini` にコピーし、必要に応じて
   使用する書庫プラグイン名を設定します。

サンプルではUnicodeパスの一覧補完（`HookFindFirstFile=1`）を有効にしています。
通常のASCIIパスは従来の高速経路を使用し、Unicode・長いパスだけ追加補正します。

3. Leeyes.exeが終了していることを確認し、LeeyesW.exeを起動します。

4. Leeyesのプラグイン設定で、使用する画像・書庫プラグインを有効にします。

通常のLeeyes.exeではなく、必ずLeeyesW.exeから起動してください。

Visual StudioでReleaseビルドを行うと、生成物は通常 `Leeyes` フォルダへ
コピーされます。実際のLeeyes本体は別途配置してください。


対応内容
--------

- Unicode文字を含むフォルダ・画像・書庫のファイルアクセスを補完
- 長いファイルパスに対するWindowsの拡張パス処理
- 画像SusieプラグインのUnicodeパスフォールバック
  - iftwebp.spi
  - IFJPEGX.SPI
  - IFPNG.SPI
  - ifavif.spi
  - WIC_Loader.spi
  - axffmpeg.spi
- `arc.spi` で読み込めないUnicodeパス上のZIP画像に対する補完
  - ZIPの無圧縮形式
  - ZIPのDeflate形式
- 通常のANSIパスでは、プラグインの通常処理をそのまま使用する高速経路
- 多重起動の補完
- WSL環境で発生するP9NPネットワークプロバイダ由来のクラッシュ回避

UnicodeパスをANSIプラグインへ渡す必要がある場合、プロセス内の合成パスや
短いパスを使用します。必要に応じて `%TEMP%\LeeyesUnicodeHack` 以下に
エイリアスを作成しますが、元のユーザーフォルダ内にはジャンクションや
ハードリンクを作成しません。


制限事項
--------

- Leeyesの画面上では、CP932で表現できない文字が「?」として表示される場合が
  あります。実際のファイルアクセスは補完されますが、表示上の文字化けを
  すべて解消するものではありません。
- 8.3短縮名は利用できる場合に優先されますが、必須ではありません。利用できない
  場合は `%TEMP%\LeeyesUnicodeHack` のジャンクション・仮想エイリアスへ
  フォールバックします。TEMPへの書込みやエイリアス作成が制限される環境、または
  物理パスを要求するSusieプラグインでは読み込めない場合があります。
- すべてのSusieプラグインや書庫形式に対応するものではありません。
- ZIP以外の書庫形式は、使用する書庫プラグインのUnicode対応状況に依存します。
- 本棚への登録、削除、名前の変更、プロパティ表示など、Leeyes本体がUnicode
  パスを扱えない操作は利用できない場合があります。
- CP932変換で`?`に置換される文字やbest-fit変換される文字を含む異なるUnicode名が
  同じバイト列へ変換され、同じフォルダ内に複数存在する場合は、元の名前を
  自動判別できないため操作できないことがあります。候補が一つだけの場合は
  実在エントリとの照合で復元します。
- 本ソフトウェアは自己責任で使用してください。
